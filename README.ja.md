**オープンソースコレクション.** MIT / CC BY 4.0 ライセンスの GitHub コレクションをもとにしたテンプレート。プロンプトは英語で書き直して整理し、日本語版と中国語版を付けています。タイトル・説明・タグは新たに作成して 18 言語に翻訳し、カバー画像はすべて新しく生成しました。ファイルはカテゴリごとに分かれています ([ファイル一覧](data/open-source/README.md)). フィールド: `slug`, `title`, `description`, `prompt_text`, `prompt_text_ja`, `prompt_text_zh`, `category`, `tags`, `model_hint`, `aspect_ratio`, `canonical_url`, `source_collection`, `license`, `cover_image_url`, `translations`.

**帰属付きスナップショット.** 原作者と元の投稿をレコードごとに残した CC BY 4.0 のレコード 286 件（2026-10-21 時点）。こちらでも公開しています： [Hugging Face](https://huggingface.co/datasets/jqyyyy/gptimagehub-prompts) ([dataset card](DATASET_CARD.md)). フィールド: `slug`, `title`, `description`, `prompt_text`, `category`, `tags`, `model_hint`, `canonical_url`, `source_author`, `source_url`, `source_collection`, `license`, `cover_image_url`, `example_image_urls`.

画像 URL は公開 CDN を指しているため、リポジトリをクローンしても画像ファイルはダウンロードされません。モデルのヒントはテンプレートの想定モデルであり、出力を検証したモデルではありません。

```python
import json
from pathlib import Path

prompts = [json.loads(line) for path in sorted(Path("data/open-source").glob("*.jsonl"))
           for line in path.read_text().splitlines()]
prompts += [json.loads(line) for line in Path("data/prompts.jsonl").read_text().splitlines()]
print(len(prompts), prompts[0]["title"], prompts[0]["cover_image_url"])
```

## MCP での利用

公式 MCP Registry に登録済み：[`io.github.jqy-yo/gptimagehub`、v1.0.0](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.jqy-yo%2Fgptimagehub/versions/1.0.0)。API キー不要で、Streamable HTTP からプロンプト検索、テンプレート全文の取得、カテゴリ一覧の取得ができます：

```json
{"mcpServers":{"gptimagehub":{"url":"https://www.gptimagehub.com/mcp"}}}
```

画像の生成には別途認証とクレジットが必要です。公開の検索機能に生成の権限は含まれません。

## 翻訳レビューのお願い

日本語・韓国語・ドイツ語・フランス語・スペイン語・ブラジルポルトガル語のネイティブの方に、[translation-review](translation-review) の訳文のレビューをお願いしています。AI によるレビューと自動チェックは済んでいますが、ネイティブの確認がまだです。詳しくは [CONTRIBUTING.md](CONTRIBUTING.md) をご覧ください。

## ギャラリーの再生成

どちらかのデータセットや作例インデックスを更新したら `node scripts/build-gallery.mjs` を実行してください。データファイルから帰属付きスナップショットのギャラリーとこれらの README を生成します。オープンソースコレクションのギャラリーはインポート処理で作られます。Markdown を出力するだけで、画像生成サービスは呼び出しません。

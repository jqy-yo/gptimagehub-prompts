URL ảnh trỏ tới CDN công khai, nên clone repository sẽ không tải tệp ảnh về. Gợi ý mô hình chỉ cho biết mẫu được viết cho mô hình nào, không phải mô hình đã kiểm chứng kết quả.

```python
import json
from pathlib import Path

prompts = [json.loads(line) for path in sorted(Path("data/open-source").glob("*.jsonl"))
           for line in path.read_text().splitlines()]
prompts += [json.loads(line) for line in Path("data/prompts.jsonl").read_text().splitlines()]
print(len(prompts), prompts[0]["title"], prompts[0]["cover_image_url"])
```

## Truy cập MCP

Có trong MCP Registry chính thức: [`io.github.jqy-yo/gptimagehub`, v1.0.0](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.jqy-yo%2Fgptimagehub/versions/1.0.0). Không cần API key, dùng Streamable HTTP để tìm prompt, lấy toàn bộ mẫu và xem danh sách danh mục:

```json
{"mcpServers":{"gptimagehub":{"url":"https://www.gptimagehub.com/mcp"}}}
```

Tạo ảnh cần đăng nhập riêng và tín dụng. Tìm kiếm công khai không bao gồm quyền tạo ảnh.

**오픈소스 컬렉션.** MIT 및 CC BY 4.0 라이선스의 GitHub 컬렉션을 바탕으로 한 템플릿입니다. 프롬프트를 영어로 다시 쓰고 정리했으며 일본어·중국어 버전을 함께 제공합니다. 제목·설명·태그를 새로 만들어 18개 언어로 번역했고, 모든 커버를 새로 생성했습니다. 파일은 카테고리별로 나뉘어 있습니다 ([파일 목록](data/open-source/README.md)). 필드: `slug`, `title`, `description`, `prompt_text`, `prompt_text_ja`, `prompt_text_zh`, `category`, `tags`, `model_hint`, `aspect_ratio`, `canonical_url`, `source_collection`, `license`, `cover_image_url`, `translations`.

**출처 표기 스냅샷.** 원작자와 원본 게시물을 레코드마다 보존한 CC BY 4.0 레코드 286개(2026-10-21 기준). 다음에서도 볼 수 있습니다: [Hugging Face](https://huggingface.co/datasets/jqyyyy/gptimagehub-prompts) ([dataset card](DATASET_CARD.md)). 필드: `slug`, `title`, `description`, `prompt_text`, `category`, `tags`, `model_hint`, `canonical_url`, `source_author`, `source_url`, `source_collection`, `license`, `cover_image_url`, `example_image_urls`.

이미지 URL은 공개 CDN을 가리키므로 저장소를 클론해도 이미지 파일은 내려받지 않습니다. 모델 힌트는 템플릿이 겨냥한 모델일 뿐, 출력이 검증된 모델은 아닙니다.

```python
import json
from pathlib import Path

prompts = [json.loads(line) for path in sorted(Path("data/open-source").glob("*.jsonl"))
           for line in path.read_text().splitlines()]
prompts += [json.loads(line) for line in Path("data/prompts.jsonl").read_text().splitlines()]
print(len(prompts), prompts[0]["title"], prompts[0]["cover_image_url"])
```

## MCP 연동

공식 MCP Registry에 등록됨: [`io.github.jqy-yo/gptimagehub`, v1.0.0](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.jqy-yo%2Fgptimagehub/versions/1.0.0). API 키 없이 Streamable HTTP로 프롬프트를 검색하고 전체 템플릿과 카테고리 목록을 가져올 수 있습니다:

이미지 생성에는 별도 인증과 크레딧이 필요합니다. 공개 검색에는 생성 권한이 포함되지 않습니다.

데이터셋이나 예시 목록을 바꾼 뒤 `node scripts/build-gallery.mjs`를 실행하세요. 데이터 파일로 출처 표기 스냅샷의 갤러리와 이 README들을 만들고, 오픈소스 컬렉션 갤러리는 가져오기 파이프라인에서 만들어집니다. Markdown만 만들며 이미지 생성 서비스는 호출하지 않습니다.

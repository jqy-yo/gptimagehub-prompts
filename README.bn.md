## MCP অ্যাক্সেস

অফিশিয়াল MCP Registry-তে তালিকাভুক্ত: [`io.github.jqy-yo/gptimagehub`, v1.0.0](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.jqy-yo%2Fgptimagehub/versions/1.0.0)। API key ছাড়াই Streamable HTTP দিয়ে প্রম্পট খুঁজুন, সম্পূর্ণ টেমপ্লেট নিন ও বিভাগের তালিকা দেখুন:

```json
{"mcpServers":{"gptimagehub":{"url":"https://www.gptimagehub.com/mcp"}}}
```

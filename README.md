## Data and licenses

| Dataset | Records | License | Files |
|---|---:|---|---|
| Open-source collection | 29,481 | MIT or CC BY 4.0, per record | [data/open-source/](data/open-source/README.md) |
| Attributed snapshot | 286 | CC BY 4.0 | [data/prompts.jsonl](data/prompts.jsonl) · [manifest.json](manifest.json) |

**Open-source collection.** Templates based on MIT and CC BY 4.0 GitHub collections, rewritten and reorganized in English with Japanese and Chinese versions, given new titles, descriptions, tags and 18-language translations, and illustrated with newly generated covers. Files are split by category ([file list](data/open-source/README.md)). Fields: `slug`, `title`, `description`, `prompt_text`, `prompt_text_ja`, `prompt_text_zh`, `category`, `tags`, `model_hint`, `aspect_ratio`, `canonical_url`, `source_collection`, `license`, `cover_image_url`, `translations`.

**Attributed snapshot.** 286 CC BY 4.0 records with the original author and post kept per record, captured 2026-10-21. Also on [Hugging Face](https://huggingface.co/datasets/jqyyyy/gptimagehub-prompts) ([dataset card](DATASET_CARD.md)). Fields: `slug`, `title`, `description`, `prompt_text`, `category`, `tags`, `model_hint`, `canonical_url`, `source_author`, `source_url`, `source_collection`, `license`, `cover_image_url`, `example_image_urls`.

Image URLs point to the public CDN, so cloning the repository does not download image binaries. Model hints describe templates, not a verified output model.

```python
import json
from pathlib import Path

prompts = [json.loads(line) for path in sorted(Path("data/open-source").glob("*.jsonl"))
           for line in path.read_text().splitlines()]
prompts += [json.loads(line) for line in Path("data/prompts.jsonl").read_text().splitlines()]
print(len(prompts), prompts[0]["title"], prompts[0]["cover_image_url"])
```

## MCP access

Official MCP Registry: [`io.github.jqy-yo/gptimagehub`, v1.0.0](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.jqy-yo%2Fgptimagehub/versions/1.0.0). Search prompts, retrieve full templates and list categories without an API key using Streamable HTTP:

```json
{"mcpServers":{"gptimagehub":{"url":"https://www.gptimagehub.com/mcp"}}}
```

Generation requires a separate authenticated workflow and credits. Public discovery does not grant generation access.

## Rebuild galleries

Run `node scripts/build-gallery.mjs` after updating either dataset or the generated example index. It renders the attributed snapshot's galleries and these READMEs from the data files; the open-source galleries come from the import pipeline. It only renders Markdown and does not call an image generation service.

import json
from pathlib import Path

prompts = [json.loads(line) for path in sorted(Path("data/open-source").glob("*.jsonl"))
           for line in path.read_text().splitlines()]
prompts += [json.loads(line) for line in Path("data/prompts.jsonl").read_text().splitlines()]
print(len(prompts), prompts[0]["title"], prompts[0]["cover_image_url"])

## MCP एक्सेस

आधिकारिक MCP Registry में उपलब्ध: [`io.github.jqy-yo/gptimagehub`, v1.0.0](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.jqy-yo%2Fgptimagehub/versions/1.0.0)। बिना API key के Streamable HTTP से प्रॉम्प्ट खोजें, पूरे टेम्पलेट लें और श्रेणियों की सूची देखें:

```json
{"mcpServers":{"gptimagehub":{"url":"https://www.gptimagehub.com/mcp"}}}
```

इमेज बनाने के लिए अलग से लॉगिन और क्रेडिट चाहिए। सार्वजनिक खोज में इमेज बनाने की अनुमति शामिल नहीं है।

# Open-source prompt collection · 开源提示词合集

28,100 image prompt templates rewritten and illustrated by [GPT Image Hub](https://www.gptimagehub.com), based on MIT and CC BY 4.0 licensed GitHub collections.

基于 MIT / CC BY 4.0 开源合集整理的 28,100 个图像提示词模板：重新编写、翻译成 18 种语言，并为每条重新生成了封面。

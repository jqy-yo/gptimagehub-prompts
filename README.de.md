# GPT Image Hub Prompts

GPT Image Hub is an open-source dataset of 30,000+ AI image prompt templates for GPT Image 2, Nano Banana and more.

**29,767 Bild-Prompt-Vorlagen mit Vorschau**, der offen lizenzierte und mit Quellen versehene Teil der 31,345 Vorlagen auf GPT Image Hub. Vollständige Prompts auf Englisch, Japanisch und Chinesisch; Titel, Beschreibungen und Tags in 18 Sprachen. Nach Kategorie stöbern, Vorlage kopieren oder direkt auf der Website generieren.

Bild-URLs verweisen auf das öffentliche CDN; beim Klonen des Repositorys werden keine Bilddateien heruntergeladen. Modellhinweise beschreiben, wofür eine Vorlage gedacht ist, kein verifiziertes Ausgabemodell.

```python
import json
from pathlib import Path

prompts = [json.loads(line) for path in sorted(Path("data/open-source").glob("*.jsonl"))
           for line in path.read_text().splitlines()]
prompts += [json.loads(line) for line in Path("data/prompts.jsonl").read_text().splitlines()]
print(len(prompts), prompts[0]["title"], prompts[0]["cover_image_url"])
```

## Quellenangabe und Lizenz

Ursprüngliche Autoren und Quell-URLs bleiben je Eintrag erhalten. GPT Image Hub ergänzt Ordnung, Korrekturen, Export-Metadaten und neu generierte Beispielbilder. Wer den Prompt-Text weiterverwendet, muss gemäß [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) die Quelle nennen und Änderungen kenntlich machen. Neu generierte Beispiele sind keine Werke der ursprünglichen Autoren.

Für Korrekturen, eine geänderte Quellenangabe oder eine Entfernung bitte Slug und Originalquelle in einem [Issue](https://github.com/jqy-yo/gptimagehub-prompts/issues) oder über die [Kontaktseite der Website](https://www.gptimagehub.com/about) senden.

## MCP-Zugang

Im offiziellen MCP Registry: [`io.github.jqy-yo/gptimagehub`, v1.0.0](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.jqy-yo%2Fgptimagehub/versions/1.0.0). Ohne API-Schlüssel über Streamable HTTP Prompts suchen, vollständige Vorlagen abrufen und Kategorien auflisten:

```json
{"mcpServers":{"gptimagehub":{"url":"https://www.gptimagehub.com/mcp"}}}
```

Für das Generieren sind eine separate Anmeldung und Credits nötig. Die öffentliche Suche umfasst keine Generierungsrechte.

## Galerien neu erzeugen

Nach Änderungen an einem der Datensätze oder am Beispielindex `node scripts/build-gallery.mjs` ausführen. Das Skript erzeugt aus den Datendateien die Galerien des Snapshots mit Quellenangabe und diese READMEs; die Galerien der Open-Source-Sammlung stammen aus der Import-Pipeline. Es erzeugt nur Markdown und ruft keinen Bildgenerierungsdienst auf.

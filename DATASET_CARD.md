## Dataset · 数据集

- [JSONL: complete prompt text, metadata and image URLs](prompts.jsonl)
- [Snapshot manifest and SHA-256](manifest.json)
- [Live dataset methodology](https://www.gptimagehub.com/prompt-dataset-methodology)
- [API documentation](https://www.gptimagehub.com/api-docs)

Each record includes a title, full prompt text, category, tags, model hint, canonical page, author, source collection, license, `cover_image_url`, and `example_image_urls`. All 286 records have a cover; six also have a newly generated example. The remaining source covers are labeled separately in the galleries. Image URLs point to the public CDN, so cloning the repository does not download image binaries.

The text snapshot was captured on 2026-10-21. Only attributed CC BY 4.0 records from the two source collections below are included; 303 other public records are excluded. Records are not deduplicated across collections. Model hints describe templates, not a verified output model.

```python
import json
from pathlib import Path
prompts = [json.loads(line) for line in Path("prompts.jsonl").read_text().splitlines()]
print(prompts[0]["prompt_text"])
print(prompts[0]["cover_image_url"])
```

## MCP access

Official MCP Registry: [`io.github.jqy-yo/gptimagehub`, v1.0.0](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.jqy-yo%2Fgptimagehub/versions/1.0.0). Search prompts, retrieve full templates and list categories without an API key using Streamable HTTP:

```json
{"mcpServers":{"gptimagehub":{"url":"https://www.gptimagehub.com/mcp"}}}
```

Generation requires a separate authenticated workflow and credits. Public discovery does not grant generation access.

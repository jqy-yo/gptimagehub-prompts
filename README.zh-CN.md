# GPT Image Hub Prompts

GPT Image Hub is an open-source dataset of 30,000+ AI image prompt templates for GPT Image 2, Nano Banana and more.

**29,767 个带配图的图像提示词模板**，是 GPT Image Hub 全部 31,345 个模板中开放许可和署名的部分。完整提示词有英文、日文、中文三个版本，标题、描述和标签覆盖 18 种语言。按分类看图，复制模板直接用，也可以在官网一键生成。

图片链接指向公开 CDN，克隆仓库不会下载图片文件。模型提示只说明模板面向的模型，不代表已验证的出图模型。

```python
import json
from pathlib import Path

prompts = [json.loads(line) for path in sorted(Path("data/open-source").glob("*.jsonl"))
           for line in path.read_text().splitlines()]
prompts += [json.loads(line) for line in Path("data/prompts.jsonl").read_text().splitlines()]
print(len(prompts), prompts[0]["title"], prompts[0]["cover_image_url"])
```

## MCP 接入

已收录于官方 MCP Registry：[`io.github.jqy-yo/gptimagehub`，v1.0.0](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.jqy-yo%2Fgptimagehub/versions/1.0.0)。无需 API key，通过 Streamable HTTP 即可搜索提示词、获取完整模板和分类列表：

```json
{"mcpServers":{"gptimagehub":{"url":"https://www.gptimagehub.com/mcp"}}}
```

生成图片需要单独登录授权并消耗积分；公开检索不包含生成权限。

## 重新生成图集

更新任一数据集或生成示例索引后，运行 `node scripts/build-gallery.mjs`。它会根据数据文件生成署名快照的图集和这几份 README；开源合集的图集由导入流程生成。脚本只生成 Markdown，不会调用生图服务。
